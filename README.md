# Nova Group — лендинг

Одностраничный сайт агентства маркетинга и онлайн-школы. Чистые HTML, CSS и JavaScript без сборки и фреймворков. Адаптирован под телефоны, планшеты и десктоп, все картинки лежат локально. Заявки из форм уходят в Telegram.

Структура блоков: шапка, первый экран с интерактивными направлениями, «О нас», агентство, обучение (вкладки «учиться / обучать»), связь агентства и школы, дорожная карта, призыв к действию, контакты. Отдельно есть страницы договора-оферты и политики конфиденциальности.

## Быстрый старт

Открывать `index.html` двойным кликом не стоит, лучше через локальный сервер.

**Только вёрстка.** В VS Code поставь расширение Live Server, нажми «Go Live». Формы при этом работать не будут, PHP он не выполняет.

**С формами.** Нужен PHP 8.0+ с расширениями `curl`, `openssl`, `mbstring`. Из корня проекта:

```bash
php -S localhost:8000
```

Открой `http://localhost:8000`. Пока `WORKER_URL` в `js/form.js` пустой, форма отправляет заявки на `server/send.php`.

Перед публикацией юридические страницы стоит показать юристу.

## Приём заявок в Telegram

Токен бота нельзя класть в код сайта: он должен жить только на сервере. Есть два варианта.

### Вариант 1. Обычный хостинг с PHP

1. Создай бота в `@BotFather`, получи токен.
2. Узнай свой `chat_id`: нажми Start у бота, напиши ему сообщение и открой `https://api.telegram.org/bot<ТОКЕН>/getUpdates`. Нужен ID чата, а не ID бота (число из начала токена).
3. Заполни `server/config.php`:

```php
return [
    'bot_token'     => '123456789:AA...',
    'chat_id'       => '123456789',
    'allowed_hosts' => ['example.com', 'www.example.com'],
    'debug'         => false,
    // необязательно, для обхода блокировок:
    'api_base'  => '',
    'relay_key' => '',
    'proxy'     => '',
];
```

4. Проверь связь командой `php server/test-telegram.php` (в Windows перед ней `chcp 65001`). Скрипт проверит расширения, токен, chat_id и отправит тестовое сообщение.

`send.php` проверяет данные, ограничивает частоту (5 заявок за 10 минут с одного IP), пишет каждую заявку в `server/leads.log` и пробует отправить её в Telegram. Если Telegram недоступен, заявка не теряется. Нужен хостинг, откуда виден `api.telegram.org`. Доступ к `config.php` и `*.log` из браузера закрывает `.htaccess` (Apache); на Nginx запрети их правилом `location`.

### Вариант 2. GitHub Pages и Cloudflare Worker

GitHub Pages отдаёт только статику, PHP там не работает. Серверную часть берёт на себя Cloudflare Worker (бесплатно).

1. В Cloudflare открой Workers & Pages, создай Worker «Hello World», нажми Edit code и вставь содержимое `worker/telegram-form-worker.js`, затем Deploy.
2. В Settings → Variables and Secrets добавь:

| Имя | Тип | Значение |
|---|---|---|
| `BOT_TOKEN` | Secret | токен бота |
| `CHAT_ID` | Secret | твой chat_id |
| `ALLOWED_ORIGIN` | Text | `https://имя.github.io` (без пути и слэша на конце) |
| `DEBUG` | Text | `1` только на время теста |

3. Открой адрес воркера в браузере: должно быть `{"ok":false,"error":"forbidden"}`. Значит, он работает.
4. Впиши адрес в `js/form.js`:

```js
const WORKER_URL = "https://novagroup-form.твоё-имя.workers.dev";
```

Папку `server/` на GitHub Pages заливать не нужно.

## Публикация на GitHub Pages

1. Создай репозиторий и залей проект.
2. Settings → Pages → Source: ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://имя.github.io/название-репозитория/`.

Все пути в проекте относительные, поэтому сайт работает и из вложенной папки.

## Безопасность

- **Не коммить токен.** Добавь в `.gitignore`:

```
server/config.php
server/leads.log
```

- Если токен попал в репозиторий, на скриншот или в чат, сразу перевыпусти его в `@BotFather` (`/mybots`, бот, API Token, Revoke).
- На рабочем сайте `debug` должен быть `false`, а в `allowed_hosts` и `ALLOWED_ORIGIN` указаны только твои домены.
- `server/test-telegram.php` работает только из консоли, но на боевой сервер его лучше не выкладывать.
- Файл `leads.log` содержит персональные данные, храни его не дольше нужного и не публикуй.

## Адаптивность

Брейкпоинты: 1024, 860 и 520 px. На телефонах включается бургер-меню, сетки складываются в одну колонку, кнопки растягиваются на всю ширину. Анимации отключаются, если в системе включено «уменьшить движение».

## Частые проблемы

| Симптом | Причина |
|---|---|
| Ошибка 404/405 у `send.php` | сайт открыт через Live Server или лежит на GitHub Pages: используй `php -S` или Cloudflare Worker |
| 502 и `Connection timed out` | с этого компьютера или сервера не виден `api.telegram.org` (блокировка провайдера или хостинга) |
| 502 и `chat not found` | неверный `chat_id` или не нажат Start у бота |
| 401 при проверке токена | токен неверный или отозван |
| Ошибка `forbidden` от воркера | `ALLOWED_ORIGIN` не совпадает с адресом сайта |
| `ERR_CONNECTION_REFUSED` | не запущен `php -S` |
